# 🍉 Juicy Merge — Quickstart & Commands

Thư mục làm việc: **`c:\Users\ADMIN\Desktop\Projects\game\M3-Juicy-Merge\game`**

## ⚡ Các lệnh thường dùng nhất:

### 1. Chạy Web Local (Phát triển & test nhanh trên trình duyệt):
```bash
npm run dev:web
# Hoặc: npm run dev
```
👉 Mở trình duyệt tại: `http://localhost:5173`

### 2. Chạy Playtest trực tiếp trên Reddit:
```bash
npm run dev:reddit
```
👉 Mở bài post Reddit tại: https://www.reddit.com/r/JuicyMerge/comments/1vywiwk/juicy_merge_drop_merge_grow/

### 3. Đóng gói ZIP nộp cho Playgama:
```bash
npm run package:playgama
```
👉 File zip xuất tại: `../build/juicy-merge-playgama.zip` (đã kèm đầy đủ asset, âm thanh và config quảng cáo)

### 4. Build & Xuất bản lên Reddit App Directory:
```bash
npm run launch:reddit
```

### 5. Chạy kiểm tra tự động (118 Tests):
```bash
npm run test
npm run test:types
npm run lint
```
