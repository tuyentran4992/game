## 3. Null Object khi standalone (PC-20)
- Mọi method không quăng lỗi (TC-SAO-01). `ads.available` ⇒ false; `showRewarded`/`showInterstitial` ⇒ trả "unavailable" ngay, KHÔNG promise treo.
- State §7 SPEC "Ad không load": ẩn nút ad, chơi bình thường, không chặn màn (TC-AD-07).
- Storage chết/ném/quota ⇒ NUỐT lỗi, chơi tiếp bằng phiên hiện tại, event `save_error` vào log (DATA-MODEL §7.2.5, TC-NET-04, TC-SAV-07).
- Nơi gọi KHÔNG phải viết `if (cóAds)` — adapter tự trả unavailable. Null Object THẬT, không rải nhánh.
- `?ad=mock` ⇒ thay ads bằng mock trả kết quả CẤU HÌNH ĐƯỢC (thành/thất bại/hẹn giờ) để test cả nhánh "ad không load" và "xem xong" (SPEC §5.4 nguyên văn).

## 4. Ad — PC-13/PC-14 ở tầng adapter
- Rewarded CHỈ 4 điểm: undo, hint, continue, x2 Mực (`ink_x2`). Policy chặn place lạ / chặn interstitial trong 60s đầu + trước khi hết màn 1 / bắt interstitial chạy SAU khi đã trao thưởng — policy ở tầng logic (đã có test TC-AD-01..07), adapter không tự quyết.
- Adapter phải GHI LẠI mọi cuộc gọi theo thứ tự (tinh thần "MockAds ghi lại thứ tự/lời gọi" — TEST-CASES nhóm F) để test soi.
- Mọi API adapter trả Promise (ad async); không block luồng chơi đồng bộ.

## 5. Lifecycle — PC-17
- `onPause`/`onResume`: mất focus ⇒ dừng timer + nhạc, resume đúng chỗ (TC-PSE-01/03/04).
- Mute nền tảng (`onAudioEnabledChange`) VÀ nút mute riêng hoạt động độc lập, ngữ nghĩa AND (TC-PSE-02).

## 6. 4 debug hooks (SPEC §5.4 — nguyên văn)
- `?debug=1` (bật overlay debug) · `?level=NN` (nhảy thẳng màn NN, KHÔNG ghi vào save thật) · `?seed=<hex>` (khoá seed để test tái lập) · `?ad=mock` (SDK ad bằng mock).
- Parse query string CHỈ ở entry/`platform/debug.ts`; logic chỉ nhận `levelIndex`/`seed` như tham số thường — `window.location` cấm trong `src/logic`.
- Hàm parse phải THUẦN: `parseDebugQuery(search: string) -> DebugFlags` — test chạy được trong node.
- Luật: 4 hook chỉ tồn tại ở build dev/standalone, strip khỏi build nộp; cổng kiểm grep `debug=` trong bundle nộp phải rỗng (kiểm thật ở B5 — B2 chỉ cần gom về 1 module + 1 chỗ gọi để strip được).
- Input rác (`?level=abc`, `?seed=zz`, `?level=-9`) ⇒ hành vi XÁC ĐỊNH, không crash, không NaN lọt vào logic.

## 8. Môi trường & bẫy
- vitest `environment: 'node'` — không có `window`/`document`/`localStorage`. Adapter đọc global LAZY lúc gọi, không đọc lúc import module.
- `tsconfig`: strict + `noUnusedLocals` + `noUnusedParameters` + `noImplicitOverride`. CẤM `any`/`@ts-ignore`.
- `npm run gate` = typecheck + `test:logic` (= `vitest run tests/logic`) + gate-smell. B2 chưa có mặt trong `test:logic` ⇒ chạy riêng: `npx vitest run tests/platform`; B2-2-code được phép sửa ĐÚNG 1 dòng `test:logic` trong package.json thành `vitest run tests/logic tests/platform`.
- `tools/gate-smell.mjs` chỉ quét `src/logic` — `src/platform` giữ cùng chuẩn: 1 file 1 trách nhiệm, header `// Pattern: <tên>`, hằng số có tên + nguồn, ≥3 nhánh ⇒ bảng tra.
