# GÓI NGỮ CẢNH B5 — build 3 nền tảng + cổng bundle + hồ sơ nộp

## Script build THẬT trong `game/package.json` (chỉ dùng đúng các này, CẤM bịa tên khác)
- `npm run build` → `tsc --noEmit && vite build`
- `npm run build:standalone` → `tsc --noEmit && vite build --mode standalone`
- `npm run build:playgama`   → `tsc --noEmit && vite build --mode playgama`
- `npm run build:ytgame`     → `tsc --noEmit && vite build --mode ytgame`
- `npm run typecheck` · `npm run test` · `npm run test:logic` · `npm run gate` (typecheck + test:logic + `node tools/gate-smell.mjs`)

## Sự thật vite.config.ts (đọc `game/vite.config.ts`)
- `base: './'` (đường dẫn tương đối — đúng chuẩn nộp), `outDir: 'dist'`, `emptyOutDir: true`.
- **BẪY LỚN NHẤT:** cả 3 mode đều ghi vào CÙNG `dist/` ⇒ build xong mode nào phải **copy ngay** `dist/ → build/<mode>/` rồi mới build mode sau. Thứ tự: `build:ytgame` → snapshot → `build:playgama` → snapshot → `build:standalone` (dist còn lại là bản dev).

## Luật bundle nộp (con số THẬT, trích nguồn)
- Zip nộp ≤ **1.6MB** = 1,677,721 B — cổng `scripts/verify_game.sh` rào ③ (án lệ các bản nộp M1/M8).
- Bundle target < **5MB**, save < **3MB**, load < **5s** — SPEC §5.2(2). `validate.py` target mỗi file < **512KB**.
- Debug hooks `?debug=1` `?level=` `?seed=` `?ad=mock` (SPEC §5.4): CHỈ được tồn tại ở build standalone/dev. **Bundle nộp (ytgame, playgama) grep 4 chuỗi đó phải RỖNG** — `debug=` là cổng cứng SPEC ghi sẵn.
- **PC-15 — CẤM mọi call mạng**: bundle grep `fetch(` · `XMLHttpRequest` · `WebSocket` · `sendBeacon` = 0; ytgame grep `https?://` = 0; playgama CHỈ được còn đúng `https://bridge.playgama.com/v2/stable/playgama-bridge.js` (script tag bắt buộc — án lệ M8 G8b: thiếu là rớt game_ready).
- DoD §8.8: không chuỗi/màn hình/metadata nào còn "GẤP" hay tên cũ; tên = **Paper Crease**.

## File metadata cần tạo (schema đối chiếu M1: `/data/youtube-playables/M1-Rescue-Dodge/metadata/metadata.json`)
- `game/metadata/metadata.json`: `title` (≤50 ký tự — luật ytgame), `short_desc` (≤150 EN), `how_to_play` (≤150 EN), `genre`, `theme`, `version`, `publisher {name: "ExcelToApp Games", contact_email: "games@exceltoapp.vn"}`, `thumbnails {"1:1","5:7","9:16","16:9"}`, `preview_video {"16:9"}`.
- Ảnh thumbnail/preview thuộc B4 (WAN). B5 **không bịa ảnh**: file thiếu ⇒ liệt kê vào báo cáo, không tự vẽ placeholder.
- Bản Playgama nộp: `dist/playgama-bridge-config.json` phải có trong bundle (án lệ M8 R2).

## Tool cổng B5 phải tạo: `game/tools/check-bundle.mjs`
Đọc thư mục snapshot, exit ≠ 0 nếu vi phạm; rule để dạng **bảng dữ liệu** (danh sách pattern + limit), không if/else dây. Kiểm: (1) grep debug-hook trong bundle nộp = 0; (2) grep network pattern; (3) tổng size thư mục + file to nhất ≤512KB; (4) index.html không còn `/src/` (đã hash) và `src=` trỏ file có thật; (5) whitelist: playgama build cho đúng 1 URL bridge.

## Quy trình build + đóng gói (thứ tự cứng)
1. `cd /data/youtube-playables/M11-Gap/game && npm run gate` (xanh mới đi tiếp).
2. `npm run build:ytgame` → copy `dist/ → build/ytgame/` → `node tools/check-bundle.mjs build/ytgame --channel ytgame`.
3. `npm run build:playgama` → copy `dist/ → build/playgama/` → `node tools/check-bundle.mjs build/playgama --channel playgama`.
4. `npm run build:standalone` (dist = bản dev, KHÔNG nộp, KHÔNG bị luật debug).
5. Zip từng bản nộp vào `build/` (tên `<game>-<channel>-<YYYYMMDD>.zip`, giữ `raw/` trong zip — án lệ REPACK-2), `diff -r` zip≡thư mục nguồn = 0 khác.
6. `python3 -m pipeline validate --game-dir /data/youtube-playables/M11-Gap` + `bash scripts/verify_game.sh M11-Gap` → dán output.
